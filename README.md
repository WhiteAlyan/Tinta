# Tinta

Local-first novel writing workspace, manuscript editor, story bible, and continuity tools in one zero-dependency PWA. 

It pairs a distraction-free manuscript editor with a full story bible — entities, relationships, maps, custom calendars, rule systems — plus craft tooling that checks continuity, tracks open questions, and remembers exactly where you left off.

Everything lives in your browser: no account, no server, no build step. Open the folder, run the launcher, write.
